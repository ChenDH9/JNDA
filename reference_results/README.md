# Reference results

These tables reproduce the complete supplemental primary endpoint record and development curves reported with the study. They are comparison targets for independently reproduced runs, not inputs to training or checkpoint selection.

The 58 seed values comprise the original systems and the additional control/baseline endpoints. The 19 descriptive rows include native seed groups and explicitly identified common-three-seed subsets. The 20 paired contrasts retain their reported uncertainty intervals. Development-selected endpoints and all 620 recorded development epochs are provided separately.

Compare like-for-like splits, checkpoints and seed sets. In particular, three-seed control summaries are not interchangeable with five-seed specialist comparisons. Statistical intervals condition on the recorded trained seeds and resample recording sessions according to the stated analysis.
